# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standards

We want participation in this project to be a harassment-free experience for everyone. Be respectful and constructive, accept feedback gracefully, and focus on what is best for the people who use the app.

Unacceptable behavior includes harassment, insults or personal attacks, sexualized language or imagery, publishing others' private information without permission, and other conduct that would be inappropriate in a professional setting.

## Scope

This code applies in all project spaces — issues, pull requests, discussions, and reviews — and when someone officially represents the project elsewhere.

## Reporting and enforcement

Report unacceptable behavior to **steve@sk-america.com**. All reports will be reviewed promptly and handled confidentially. Maintainers may remove, edit, or reject contributions, and may temporarily or permanently ban contributors whose behavior violates this code, following the enforcement guidelines of the Contributor Covenant.
