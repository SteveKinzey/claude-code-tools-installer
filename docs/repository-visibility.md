# CCTI repository visibility

## Current state

As checked on September 2, 2026, `SteveKinzey/claude-code-tools-installer` is a **public** GitHub repository.

## Does CCTI need a public repository?

No. The CCTI desktop app can set up Claude Code, show its catalog, explain choices, install supported prerequisites, and manage its own checked locations without any visitor having GitHub access.

## Why keep it public?

A public repository can let advanced users inspect CCTI source code, view release history, and verify source-controlled release files. It is not required for normal setup. The normal product path stays in CCTI, and external technical sources are optional in the References area.

## What changes if it becomes private?

The app still works, but GitHub release-download links must be replaced with signed CCTI-hosted assets, and public source and release-history links will no longer be available. Any visibility change needs explicit owner approval; CCTI must not change GitHub visibility automatically.
