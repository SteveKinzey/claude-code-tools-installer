## Integrity & Distribution Rules

1. **macOS Delivery:** Public macOS delivery uses Developer ID-signed, notarized, stapled ARM64 DMGs only. Unstapled ZIP candidate files are excluded from public release assets.
2. **Windows Delivery:** Windows users are directed to the Microsoft Store. Direct non-Store ZIP packages are discontinued to prevent untrusted execution warnings.
3. **SHA-256 Gating:** The public product site at `claudetool.app` queries GitHub release metadata and serves installer downloads only when the release exposes a validated SHA-256 digest.
4. **Continuity Fallback:** If GitHub API experiences transient outages or rate limits, the site seamlessly falls back to bundled verified metadata so users are never left with broken download buttons.
