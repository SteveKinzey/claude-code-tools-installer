## Detailed Changelog & Release Notes

### 1. In-App "Verify Setup" Panel (Step 1)
- **One-Click Local Health Check:** Directly check the operational readiness of your Claude Code environment without opening Terminal or PowerShell.
- **Granular Status Reporting:** Inspects Claude Code CLI, Bun runtime, gstack skills, taste-skill, Planning with Files, Repomix CLI & MCP connection, Playwright MCP server, Superpowers plugin, Claude HUD, and the official Anthropic Skills marketplace.
- **Fail-Safe & Read-Only:** Queries only known local paths and runs bounded, hidden checks. Does not mutate files, inject unreviewed code, or open arbitrary shell processes.

### 2. Resolved gstack Upstream Container Warning
- **Upstream Notice Classification:** Upstream gstack setup emits `No qualified CSO images are published for this platform; static audits remain available.` on macOS and Linux systems lacking custom container configurations.
- **Marker-Based Verification:** CCTI now verifies gstack by inspecting its core completion artifacts (`~/.claude/skills/gstack/setup`, `VERSION`, `browse/dist/browse`, and `health/SKILL.md`).
- **Clear Guidance:** If the artifacts exist, CCTI reports gstack as **Ready**. If incomplete, CCTI points users back to Complete setup rather than failing silently.

### 3. Automated In-App Plugin Setup
- **Zero Command Copying:** When choosing "Complete setup", CCTI passes `--app-managed-plugins` to the platform adapter, installing reviewed plugins directly via official non-interactive CLI commands.
- **Supported Out of the Box:** Automatically installs and enables Superpowers, Claude HUD, and registers the official Anthropic Skills marketplace (`anthropics/skills`).

### 4. Release Distribution & Security
- **macOS Direct Distribution:** Apple Silicon DMG signed with Developer ID Application, Hardened Runtime, notarized by Apple, stapled, and verified against Gatekeeper.
- **Native Auto-Updater Feed:** Includes verified `Claude-Code-Tools-Installer-2026.9.22-mac-arm64.zip` and SHA-512-backed `latest-mac.yml` feed for in-app updates.
- **Zero High-Severity Vulnerabilities:** Full security scan (`npm audit --audit-level=high`) returned 0 findings.
- **Windows Policy:** Windows MSIX submission remains uncoupled from direct tool usage. Unsigned executable distribution remains blocked until the dedicated code-signing workflow is deployed.
