Claude Code Tools Installer

Set up Claude Code, choose your workflow tools, and add Convex components to the right project.

Checking Claude Code…
No command-line steps are required in this app. Start by setting up Claude Code, choose only the tools you want, and review every change before it runs. Project-level Convex packages are kept separate so they never install in the wrong folder.

OPTIONAL TECHNICAL HELP

References

Normal setup and tool details stay in CCTI. Open this only for original source pages, exact package names, and technical words.

Project folderThe folder that holds one app you are building. Project features go there.
PackageA small piece of app code. CCTI adds it only to the project folder you choose.
Plugin or skillAn optional helper for Claude Code. It belongs in your Claude Code setup.
MCP connectionA connection between Claude Code and another service. It may require that service’s sign-in.
RuntimeA helper program, such as Node.js, that lets some tools run. CCTI prepares supported ones when needed.

These links open websites run by other organizations. They are optional and can use more technical language than CCTI.
